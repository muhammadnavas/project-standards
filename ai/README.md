# AI and Coding-Agent Standards

This directory contains reusable guidance for AI-assisted development.

## Files

- `system-prompts.md`: reusable project-level instruction prompt.
- `coding-agent.md`: practical behavior rules for repository-aware coding agents.

## Usage

Use these as a starting point, not as a substitute for project context. Add project-specific requirements, architecture, commands, constraints, and acceptance criteria.

Keep instructions concise, non-contradictory, and verifiable. Do not put secrets, private user data, or credentials in prompts. Review all generated changes as normal code.
